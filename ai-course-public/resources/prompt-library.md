## 1. Content Creation Prompts

### Blog Post Writer
```
Act as an expert blog writer. Write a 1500-word blog post on [topic].

Target audience: [describe]
Tone: [professional/casual/friendly]
Structure:
- Hook (first 100 words)
- 3-5 main points with subheadings
- Real examples for each point
- Actionable takeaways
- Conclusion with CTA

Include:
- Bullet points where appropriate
- Bold key phrases
- 1-2 relevant statistics per section
- A compelling meta description (155 characters)
```

### Social Media Calendar
```
Create a 30-day social media content calendar for [my business type] in [city/country].

Platforms: [Instagram/Facebook/LinkedIn/TikTok]

Content pillars (rotate evenly):
- Educational (40%)
- Behind the scenes (20%)
- Customer stories (20%)
- Promotional (20%)

For each day, provide:
- Day number and date
- Platform
- Content type (image, video, carousel, story)
- Caption (150-200 words)
- 5-10 relevant hashtags
- Best time to post

Make it actionable and specific to my business.
```

## 12. Templates Library

### The "Perfect Prompt" Formula

```
ACT AS: [specific role with experience]
TASK: [what you want done]
CONTEXT: [background information]
CONSTRAINTS: [limitations, requirements]
FORMAT: [how you want output structured]
EXAMPLES: [show what good looks like]
TONE: [voice and style]
```

### Example Using Formula:
```
ACT AS: Expert copywriter with 15 years experience writing for SaaS
TASK: Write 5 email subject lines
CONTEXT: Product is AI writing tool. Audience is content marketers.
CONSTRAINTS: Under 50 characters. Create curiosity. No clickbait.
FORMAT: Numbered list with brief explanation of each
EXAMPLES: 
- "The 3-word email that got 47% open rate"
- "Why I deleted my writing software"
TONE: Conversational, not salesy
```

### The "Iteration" Formula

After getting AI's first response, try:

1. "Make it more [specific adjective]"
2. "Give me 3 more variations"
3. "What's missing?"
4. "Make it shorter" or "Make it longer"
5. "Add an example"
6. "Change the tone to [X]"
7. "Who would disagree with this?"
8. "What's the counter-argument?"
