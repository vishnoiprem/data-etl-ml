3. **Live, in production, observable** — Every project runs in your own cloud account (free tier). You see your work in a real browser, with real metrics. No "trust me, it works" — you watch it work.

## The 6 Data Systems You'll Master

Every project connects to one or more of these 6 real data systems. By Day 180, you'll be fluent in integrating AI with production data infrastructure.

### System 1: PostgreSQL (Days 1-30)
**Why:** Most AI features need structured data. Postgres is the universal backend.
**You learn:** pgvector for embeddings, pgvector + LLMs, querying with natural language, auto-SQL generation, schema understanding, RAG over SQL data.
**Setup:** Free Postgres on Neon, Supabase, or Railway.

### System 2: REST APIs & Webhooks (Days 31-60)
**Why:** Every SaaS product is an API. AI needs to talk to them.
**You learn:** Calling APIs, parsing responses, error handling, OAuth, rate limiting, webhook receivers, async processing, API synthesis.
**Setup:** Use public APIs (GitHub, Stripe, OpenWeather, Notion, Slack) + build your own.

### System 3: Document Stores & Search (Days 61-90)
**Why:** Most real-world data is unstructured (PDFs, emails, logs, tickets).
**You learn:** MongoDB, Elasticsearch, OpenSearch, full-text search, semantic search, hybrid search, document Q&A, PDF parsing, OCR.
**Setup:** MongoDB Atlas free tier, local Elasticsearch via Docker.

### System 4: Object Storage & Files (Days 91-120)
**Why:** AI needs to read images, PDFs, audio, video, CSVs at scale.
**You learn:** S3-compatible storage, file processing pipelines, image generation, audio transcription (Whisper), OCR, PDF extraction, batch processing.
**Setup:** Cloudflare R2 (free), AWS S3 free tier, Backblaze B2.

### System 5: Message Queues & Streams (Days 121-150)
**Why:** Production AI runs on events. Kafka, Redis Streams, RabbitMQ.
**You learn:** Event-driven AI, real-time processing, async pipelines, queue workers, pub/sub, dead-letter handling, observability.
**Setup:** Upstash Redis (free), CloudAMQP RabbitMQ (free), Redpanda (Kafka-compatible).

### System 6: Vector Databases & Embeddings (Days 151-180)
**Why:** Modern AI is built on vector search. RAG, recommendations, semantic search.
**You learn:** Pinecone, Weaviate, Qdrant, Chroma, pgvector at scale, hybrid search, re-ranking, multi-modal embeddings, ANN algorithms.
**Setup:** Pinecone free tier, Weaviate Cloud, Qdrant Cloud, or self-hosted Chroma.

## The "Day 1" Experience

> **Concept:** "AI can answer questions about your data"
>
> **Project:** Build a SQL query generator
> Given a PostgreSQL database with a users table, write a function that takes a natural language question ("How many users signed up last week?") and returns a valid SQL query.
>
> **What you build:**
> ```python
> def text_to_sql(question: str, schema: str) -> str:
>     response = client.chat.completions.create(
>         model="gpt-4o-mini",
>         messages=[
>             {"role": "system", "content": f"Schema: {schema}\\nGenerate SQL."},
>             {"role": "user", "content": question}
>         ]
>     )
>     return response.choices[0].message.content
> ```
>
> **Test it:**
> ```python
> print(text_to_sql("How many users signed up this month?", users_schema))
> # → "SELECT COUNT(*) FROM users WHERE created_at >= DATE_TRUNC('month', NOW());"
> ```
>
> **Deploy it:** Streamlit app, run locally, push to GitHub. Done.
>
> **Time:** 30 minutes.

That's Day 1. By Day 30, you'll be doing this in your sleep.

## FAQ

**Q: I only have 30 min/day. Can I still do this?**
A: Yes. 80% of daily projects take 30-45 min. The 20% that take longer (60-90 min) are clearly marked so you can plan ahead.

**Q: I'm not a Python dev. Can I use JS/TS?**
A: The starter code is Python, but the concepts are language-agnostic. JS/TS students get a parallel track in the community (translate each project to TypeScript).

**Q: What if I miss a day?**
A: No penalty. The course is self-paced. You can catch up on weekends. Most students miss 5-10 days over 6 months (vacations, work emergencies).

**Q: Do I need to deploy everything?**
A: Strongly recommended but not required. Local-only is fine for learning. But "I deployed 180 things" is a much stronger portfolio than "I built 180 things."

**Q: What's the time-to-first-value?**
A: 30 minutes. By end of Day 1, you have a working AI app. By end of Week 1, you have 7 working apps. By end of Month 1, you have a portfolio piece you can show in interviews.

**Q: What cloud costs should I expect?**
A: $0-10/month total. All 6 data systems have generous free tiers. If you stay within free tiers, your cost is $0. If you go beyond (e.g., production SaaS at Day 180), budget $20-50/month.

**Q: Can I expense this through my employer?**
A: Yes. We provide invoices. Most companies have a learning budget ($1,500-3,000/year).

**Q: Is this the same as AI Engineer Mastery?**
A: Different course, different format. AI Engineer Mastery is a structured 35-hour curriculum (videos + theory + projects). AI Daily is a 6-month daily practice (one project per day, 180 projects total). They're complementary — many students take both.
