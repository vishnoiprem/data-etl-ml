# Per-Lesson Practice Labs — AI Engineer Mastery

> **The hands-on lab manual. One lab per lesson in [the Mastery outline](../outlines/ai-engineer-mastery.md).**
> Every lab is delivered in 3 formats: Markdown spec, runnable Python file, Jupyter notebook.

---

## How to use this

1. **Read** the corresponding lesson in [`../outlines/ai-engineer-mastery.md`](../outlines/ai-engineer-mastery.md)
2. **Open** the matching lab here (same lesson number)
3. **Pick your architect level** from the checkbox grid at the top
4. **Build** using the `.py` or `.ipynb` file
5. **Read the architect notes** at the bottom — these don't exist in any other AI course
6. **Reflect** with the 4 questions

## File format per lab

Each lesson produces **3 files** in the same folder:

| File | Purpose |
|---|---|
| `lesson-X-Y-topic.md` | Spec + architect notes (this is the human-readable guide) |
| `lesson-X-Y-topic.py` | Runnable Python code: starter with TODOs + complete solution in one file |
| `lesson-X-Y-topic.ipynb` | Same content as .md + .py, in Jupyter notebook form for interactive execution |

If you only have time to read one file per lesson, read the **.md**. It contains everything including the architect notes.

---

## Architect depth — what each level actually does

The same lab file contains all 4 levels. You self-select via the checkbox grid at the top of every lab.

| Level | Checklist | What you ship |
|---|---|---|
| 🟢 Junior | Implement and run. Tests pass. README written. | Working tutorial-grade code |
| 🟡 Mid | Junior + observability (logs, metrics, traces), retries, basic error handling | Production-grade prototype |
| 🟠 Senior | Mid + multi-tenant isolation, per-tenant rate limits, cost guardrails, SLO definition | Production SaaS foundation |
| 🔴 Staff | Senior + ADR for the major design decision, capacity model at 100× scale, on-call runbook, postmortem template | Production-grade system + the docs to operate it |

The Markdown and code are the same for all 4 levels. The **architect notes** are different — they explicitly call out the 4 levels.
