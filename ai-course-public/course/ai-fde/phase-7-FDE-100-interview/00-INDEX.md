# FDE/FDSE Interview Prep — Top Companies Index

This directory contains per-company interview prep files for the **top 15 employers of Forward Deployed Engineers (FDEs) / Forward Deployed Software Engineers (FDSEs)**.

Each file contains:
- Company snapshot (HQ, team size, comp, what they deploy, travel)
- Interview process (rounds, length, who's on the loop)
- **✅ SUCCESS STORIES** — actual Q&A from candidates who got offers, plus "why it worked"
- **❌ REJECTION STORIES** — actual Q&A from candidates who didn't, plus "why it failed" + the better answer
- **📚 Reading list** — the specific articles/docs/papers to read

## How to Use

1. Pick **3–5 target companies** from your preferred tier.
2. Read the company file end-to-end (snapshot → process → success → rejection → reading list).
3. For each Q in the success section, **practice answering out loud** for 60–90 sec.
4. For each rejection section, **write the better answer in your own words**, then say it.
5. Drill the reading list items in the **last 2 weeks** before each loop.

## Cross-Cutting Themes (across all 15 companies)

1. **Coding + customer scenario + system design** is the universal 3-act structure.
2. **Object modeling** (Palantir) → **ML system design** (Anthropic, Mistral, Cohere, OpenAI) → **compliance + privacy design** (reg-heavy: Helsing, Shield, Cohere, Databricks).
3. **Rejections cluster around**: skipping root-cause, dismissing customer concerns, not knowing the company's actual products/SKUs, not measuring success.
4. **Wins cluster around**: specific past deployments, named product primitives, week-by-week rollout plans, evaluation-first thinking, root-cause methodology, stakeholder empathy.
