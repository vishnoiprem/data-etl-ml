## ✅ SUCCESS STORIES

### Cloud scenario
**Q:** *"Retailer wants AI.Cloud to migrate 50 ML models to AWS."*
**A (winner):** *"Discovery workshop on-site. Re-platform each model on SageMaker, containerize, deploy via SageMaker Pipelines. Pilot 5 models, expand 5/quarter. Cost via Compute Savings Plans. Gov / SOC2 controls baked in. Handoff with customer's MLOps team."*
**Why it worked:** Concrete plan with TCS-native practice name.

---

## ❌ REJECTION STORIES
### Cloud scenario
**Q:** *"Models are failing in prod."*
**A (loser):** "We'll redeploy."
**What they should have said:** *"Diagnose: data drift, infra issue, or model logic? Add SageMaker Model Monitor for drift. Add alarms. Add runbook. Patch with shadow deployment first."*
