# Companion Courses — GenAI prep beyond the Phase 1-5 curriculum

> **The Phase 1-5 curriculum teaches FDE. The GenAI interviews (`../README.md`) test whether you can ship LLMs in production. The best FDE candidates pair the Phase 1-5 curriculum with a companion GenAI course that builds the technical artifacts.** This directory cross-references the most-cited GenAI courses to the Phase 1-5 modules, so you can pick the one that fits your style and your target company.

---

## The 5 questions every companion course entry answers

1. **What is the course?** (instructor, platform, length, structure)
2. **What does it teach that Phase 1-5 doesn't?** (the 3-5 things Ed / Karpathy / DeepLearning.AI / Chip Huyen add)
3. **What does it miss that Phase 1-5 adds?** (the FDE gaps — eval-set-as-spec, cost ceiling, circuit breaker, handoff, customer simulation)
4. **How does it map to Phase 1-5?** (project-by-project cross-reference)
5. **Who is it for?** (target company + target role)

## How to use this directory

1. **Pick a course.** If you want the most balanced (8 projects, 8 weeks, all the FDE patterns), start with Ed Donner. If you want the deepest technical foundation, start with Karpathy. If you want the most agent-focused, start with DeepLearning.AI. If you want a single reference, start with Chip Huyen.
2. **Read the cross-reference.** Each entry's § "The cross-reference" maps the course's projects to the Phase 1-5 modules. Use this to plan your study order.
3. **Build the FDE additions.** Each entry's § "The 8-week FDE upgrade plan" lists the 3 FDE additions per project. Add these as you build the projects.
4. **Add new entries.** Found a great GenAI course? Add it to this directory. The pattern is the 5 questions above.

## The thesis

Phase 1-5 teaches the FDE pattern. The companion courses teach the technical craft. **The complete FDE candidate pairs both** — they can build the artifact (Ed's 8 projects) AND ship it to a customer (Phase 1-5's eval-set-as-spec, cost-ceiling-as-score, handoff-as-proof, state-externalization-as-precondition).

**Build the artifact. Ship it to a customer. Hand it off. That's the FDE.**
