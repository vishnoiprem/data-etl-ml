Day 1
30 min · Easy · Postgres

Text-to-SQL Generator

💡 Concept: LLMs can translate natural language to SQL if you give them the schema. This is the foundation of "AI for databases."

🛠️ Project

Build a function that takes a question in English and returns a valid SQL query.

Code

from openai import OpenAI
from db import query

client = OpenAI()

def text_to_sql(question):
    response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[
            {"role": "system", "content": "You are a SQL expert. Schema: users, orders, products. Return only SQL."},
            {"role": "user", "content": question}
        ],
        temperature=0
    )
    return response.choices[0].message.content

print(text_to_sql("How many users signed up this month?"))
