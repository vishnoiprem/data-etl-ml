## Stage 2: Technical phone screen (60 min)

### Q2.1: "Implement a state-space model (S4 / Mamba) forward pass"
**Answer:** SSM: `h_t = A·h_{t-1} + B·x_t; y_t = C·h_t + D·x_t`. Selective (Mamba): make B, C, Δ input-dependent: `B = Linear(x), C = Linear(x), Δ = softplus(Linear(x))`. The discretization: `Ā = exp(Δ·A), B̄ = (Ā - I)·A⁻¹·B`. Compute: parallel scan over the sequence.
```python
import torch
def ssm(x, A, B, C, D):
    # x: (B, L, d_in); A: (d_in, d_state); B: (B, L, d_state); C: (B, L, d_state)
    h = torch.zeros(x.size(0), A.size(0)); ys = []
    for t in range(x.size(1)):
        h = torch.einsum("bd,dn->bn", x[:, t], B[:, t]) + torch.einsum("dn,bn->bn", torch.exp(A), h)
        ys.append(torch.einsum("bn,bn->b", h, C[:, t]) + D * x[:, t])
    return torch.stack(ys, dim=1)
```
Mamba is the AI21-canonical architecture.
**Tip:** Selective SSM + parallel scan is the Mamba core.

## Stage 3: Onsite (4 rounds)

### Round 3.1: Coding (60 min)

### Q3.1.1: "Top-K elements in a stream, O(n log K)"
**Answer:** Min-heap of size K. For each new element, push and pop if size > K. Final heap = top K.

### Q3.1.2: "LRU cache, thread-safe"
**Answer:** `OrderedDict` for LRU; `threading.Lock` for thread safety; sharded locks for concurrency.

### Round 3.2: ML deep-dive (60 min)

### Q3.2.1: "Compare Mamba vs. Transformer vs. Jamba hybrid"
**Answer:** Transformer: O(n²) attention, strong in-context learning, slow on long context. Mamba (SSM): O(n) compute, linear memory, weaker in-context learning on short context. Jamba: hybrid — Mamba layers for most, attention layers for the in-context recall. Trade-off: Jamba gets both speed and recall, but the ratio matters (1:7 attention:SSM is the AI21 default).
**Tip:** Hybrid ratio + linear-time compute is the Mamba story.

### Q3.2.2: "Implement grouped-query attention (GQA) with KV cache"
**Answer:** Multiple query heads share the same K/V head; cache size reduces by the GQA ratio. On inference: cache shape = (n_kv_heads, seq, d); query shape = (n_heads, seq, d); broadcast K/V to query shape before attention.
