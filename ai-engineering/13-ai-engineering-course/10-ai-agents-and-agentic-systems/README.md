## Course Promise

> "Design a single agent, give it tools and memory, and scale it to a multi-agent system."

The agent curriculum: from "what is an AI agent" through function calling, the agent loop, ReAct, Plan-and-Execute, Reflection, memory, MCP, Agent Skills, OKF, multi-agent systems, SubAgents, orchestration, computer-use agents.
