# Module 1 — Machine Learning Foundations

> Source: Outcome School · Module 1 · 9 lessons

---

## Course Promise

> "Know what a model is, how it learns from data, how we measure it, and how we stop it from overfitting."

By the end of this module, you'll be able to explain supervised vs unsupervised learning, the difference between L1 and L2 loss, what precision and recall mean, and why regularization exists — all with the math.
