## The Question Categories

| Category | Sample questions |
|---|---|
| ML Foundations | What's the bias-variance tradeoff? Why is cross-entropy better than MSE for classification? |
| Deep Learning | Walk me through backpropagation on a 2-layer network. Why does dropout work? |
| Transformers | Derive the Q/K/V attention formula. Why scale by √dₖ? What is causal masking? |
| Fine-tuning | When do you fine-tune vs prompt-engineer vs RAG? Walk me through LoRA. |
| RAG | Compare vector search, BM25, hybrid. When would you use GraphRAG? |
| Agents | What's the difference between ReAct and Plan-and-Execute? How do you stop an agent from looping forever? |
| Inference | What's the difference between prefill and decode? How does speculative decoding keep the same output? |
| Evaluation | How do you build an LLM eval set? What's wrong with using the same model as a judge? |
| Safety | Walk me through a prompt-injection attack and the defenses that work. |
| System Design | Design a real-time voice AI agent at 10K concurrent calls. |
