## Module Outcomes

By the end of Module 3 you can:

1. **Generate** complete ingestion pipelines with explicit edge cases, not happy-path-only code.
2. **Optimise** Spark jobs by combining AI hypothesis-generation with EXPLAIN plans and cluster configs.
3. **Scaffold** dbt projects end-to-end (sources → staging → marts) with conventions encoded in `CLAUDE.md`.
4. **Compose** Airflow DAGs from a canonical template, with retries, callbacks, and tests in place.
5. **Automate** test authoring for SQL, PySpark, and DAGs using AI as a test-generation partner.
6. **Generate** documentation, schema.yml, and lineage notes at >85% coverage with human refinement.
7. **Reason** about self-healing pipelines — what to auto-retry, what to alert, what to escalate.
8. **Verify** every AI-generated artifact against the same gates human code goes through.
