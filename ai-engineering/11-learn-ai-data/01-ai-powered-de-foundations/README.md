## Module Outcomes

By the end of Module 1 you can:

1. **Map** the AI-for-DE landscape: which problems are LLM-shaped vs. classical-ML shaped vs. rule-shaped.
2. **Describe** how the daily DE workflow changes when you adopt an AI pair-programmer.
3. **Configure** a working IDE-AI environment (Cursor / Copilot / Claude Code / Aider / Continue).
4. **Apply** core prompt-engineering patterns (few-shot, chain-of-thought, structured output, tool use).
5. **Defend** a "trust but verify" position: where AI accelerates, where it must be gated.
6. **Operate** an AI-augmented workflow: spec → draft → review → test → ship.
7. **Reason** about ethics, IP, privacy, hallucination, and bias risks specific to data systems.
