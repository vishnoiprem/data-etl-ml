## Key terms

- **Python:** the programming language we'll use in this course. It's the
  language that AWS Lambda supports natively and the language almost every
  AWS SDK example is written in.
- **PyCharm Community Edition:** the editor we'll use to write Python code.
  It's free, it runs on Windows/macOS/Linux, and it works the same way on
  every operating system.
- **Script:** a plain text file that contains a sequence of Python
  instructions, saved with a `.py` extension. You "run" the script and the
  computer does what the instructions say.

## Lecture

Welcome to the Python Basics Appendix. This is the section of the course for
anyone who has never written Python before — or anyone who tried Python once,
got confused, and walked away.

Three things before we start.

**One, you can skip this section.** If you already write Python code in your
day job — even a little — there is nothing here you need. Skip to Section 15
or Section 16. The whole course works without this appendix.

**Two, this section is paced for absolute beginners.** Every step is shown.
Every term is defined when it's first used. We never assume you know what a
"variable" or a "function" is. We never assume you've ever opened an IDE.

**Three, what you'll be able to do by the end.**

- Open PyCharm, create a new file, type Python, and run it.
- Use `print()` to display text.
- Store information in variables — numbers, text, true/false flags.
- Format strings with f-strings so your output looks clean.
- Read keyboard input from the user with `input()`.
- Tell the difference between `int`, `float`, `str` and `bool`.
- Use `for` and `while` to repeat work.
- Build and read dictionaries.
- Build and read lists.
- Define your own functions with parameters and `return` values.

That's exactly what L79, L80 and L81 cover, in that order.

L79 — PyCharm, `print`, variables, f-strings, `input`. About nine minutes.
L80 — data types, `for` loops, dictionaries. About thirteen minutes.
L81 — lists, list methods, functions. About nine minutes.

That's the whole section. Let's go.
