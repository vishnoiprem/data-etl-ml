# Required to build a pipeline *inside* a Jupyter/IPython kernel.
#
# This is not optional and not a "dataframe API" choice. When Beam detects
# that it is running inside IPython — which is every notebook in this
# course — it imports its interactive runner to label transforms with
# their cell number. That module does `import pandas` at the top level,
# so a missing pandas breaks `beam.Pipeline()` with:
#
#   ModuleNotFoundError: No module named 'pandas'
#
# raised from apache_beam/runners/interactive/utils.py
#
# The upper bound matters. Beam 2.77 builds its DataFrame wrappers by
# reflecting over `pandas.DataFrame`, and pandas 3.0 removed
# `DataFrame.first`. With pandas 3.x, constructing a pipeline inside a
# notebook fails with:
#
#   AttributeError: type object 'DataFrame' has no attribute 'first'
#
# raised from apache_beam/dataframe/frame_base.py. Pin below 3.0 until
# Beam ships support for it.
pandas>=2.0.0,<3.0.0
