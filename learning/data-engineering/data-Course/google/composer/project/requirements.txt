# Note what is NOT here: apache-airflow.
#
# The business logic in project/core/ imports nothing from Airflow, so the
# tests and the local runner work on a bare Python install. This is the
# entire premise of the course: learn Airflow through Composer without a
# local Airflow install that would not match Composer's version anyway.
#
# If you want to parse the DAG files locally, install Airflow in a SEPARATE
# virtualenv and pin it to your Composer's Airflow version:
#
#     python3 -m venv .venv-airflow
#     source .venv-airflow/bin/activate
#     pip install "apache-airflow==2.9.3" \
#       --constraint "https://raw.githubusercontent.com/apache/airflow/constraints-2.9.3/constraints-3.11.txt"
#
