# Round structure: Meta Data Engineer, Product Analytics (DE-PA)

Nothing here is specific to Singapore. No source gave a Singapore-specific loop. Search snippets say DE-PA roles are posted in Singapore, Austin and London, so the same loop is assumed. That is an assumption, not a finding.

## 1. What Meta itself says (official prep PDF)

Source: Meta "Data Engineering Onsite Interview Guide" — https://d3no4ktch0fdq4.cloudfront.net/public/course/files/Meta_DE_onsite_prep_guide.pdf (undated, written for an in-person whiteboard onsite, so older than the virtual loop).

- Onsite is about 5 hours: three technical interviews of 1 hour each, one Ownership interview of 30 minutes, and a 1 hour lunch.
- The three technical interviews together assess product sense, analysis, data modeling, SQL/ETL and coding. All three are "case studies of typical product challenges that we solve with data".
- Data modeling: brainstorm the data needs of a user product, design a data mart for analytics use cases, then write SELECT statements for specific results.
- SQL: basic constructs. Joins, aggregates, analytical functions, set operators, subqueries. Also how to load and transform logging data into the target tables.
- Coding: data structures, strings, sets, dictionaries, lists, loops. Python, Java or Scala.
- Ownership: questions about past experiences where you took initiative and influenced other data engineers and cross-functional partners.
- Meta's tips: listen for hints, think out loud, ask clarifying questions, favour breadth over depth, give specific reasons for wanting to work at Meta.

## 2. Loop as candidates describe it (2024 to 2026)

| Stage | What candidates report | Source |
|---|---|---|
| Recruiter screen | 30 min: background, "Why Meta?", "Why data engineering?" | Aced experience; Prepfully |
| Technical screen | 60 min on CoderPad: about 25 min SQL (5 questions) + about 25 min Python (5 questions) + intro and wrap-up. Code must run against test cases. Speed matters more than difficulty. | Blind dmaiuddo, ac4iko6f, q34wvvus (comment by a Meta employee), dlb8rr6f |

## 3. Older formats (do not assume they apply now)

- 2021 onsite: three interviews. 6-7 SQL queries plus one medium Python question in 6 minutes plus product sense; data model and SQL over that model; key metrics plus a medium SQL question plus a streaming Python question. Source: https://www.teamblind.com/post/facebook-data-engineer-onsite-interview-hreywvor
- 2022 virtual onsite described as "Behavioral + ETL", "SQL / Batch ETL with Python", "Streaming + Data Modelling". Source: https://www.teamblind.com/post/meta-data-engineering-onsite-prep-zeyrzlfm
- Guide-site timings such as 10 / 15 / 15 / 15 minutes per component appeared only in search snippets and were not confirmed on a fetched page. Not used.

## 4. Levels

Candidates mention E4 (IC4) and E5 (IC5) DE-PA loops with the same structure. Blind mvjlpe5q found no clear E4 vs E5 difference in interview content.

## 5. Contradictions to be aware of

- Prepfully and Aced describe 4 sessions (3 technical + 1 ownership). Datavidhya says "4 rounds, 45 to 60 min each, no standalone behavioral round". The two cannot both be right; Meta's own PDF and the Blind candidates support the standalone Ownership round.
- The Aced experience shows a separate 30 min behavioral round before the loop. Other sources fold it into the loop day.
