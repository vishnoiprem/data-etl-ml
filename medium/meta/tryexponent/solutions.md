## Quick reference — process at a glance

```
Recruiter screen    30 min   fit + motivation + prep handoff
Technical screen    60 min   5 SQL + 5 Python, 3/3 pass bar, CoderPad
Onsite              1 day    4 blended rounds × 60 min  +  1 behavioral × 30 min
```

**The blend in every onsite round:** product sense → data modeling → SQL → Python, all on the same case.

---

## Quick reference — the four skill areas

| Skill | Weight | What interviewers score |
|-------|--------|------------------------|
| Product sense | High (frames everything) | Translates a product case into the data questions that need answering |
| Data modeling | **Highest** | Fact/dim tables, PKs/FKs, many-to-many, partitioning, indexing, ETL awareness |
| SQL | Core | Joins, GROUP BY, CTEs, window functions, aggregations + business reasoning + scale |
| Python | Core | Strings, dicts, file I/O, exceptions, streaming/windowing patterns |

---

## Quick reference — common pitfalls (from the guide)

- Skipping clarifying questions before designing or coding
- Over-engineering SQL when a simpler query works
- Ignoring scale trade-offs in data modeling
- Narrating only at the end instead of as you work
- Mixing up PKs/FKs in schema design
- Going over the 5-min behavioral cap
