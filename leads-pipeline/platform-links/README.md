## Setup priority (do these first)

1. **Upwork** (1 hr) — biggest volume, fastest first contract
2. **Toptal** (1 hr) — highest rate, but screening is real
3. **A.Team** (30 min) — best for AI pods
4. **LinkedIn** (1 hr) — flip location to HCMC, set "Open to Work", follow 50 founders
5. **X** (30 min) — set bio, banner, follow target accounts
6. **Glints + JobStreet** (30 min) — APAC direct
7. **Braintrust + Arc + Lemon** (1 hr) — fill in
8. **Wellfound + RemoteOK + Remotive** (30 min) — set alerts

**Total setup time: ~6 hours** for a complete platform presence.
After that, daily 60-90 min to scan + submit.
