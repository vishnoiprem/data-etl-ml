## 🔄 Cross-Source Validation Method

### For Each Question Theme:
1. **Collect** all variants from 3+ sources
2. **Identify** common core (what's asked 80%+ of time)
3. **Note** source-specific nuances (Singapore vs global, manager vs peer)
4. **Build** master answer incorporating best elements
5. **Tag** by round and practice frequency

### Example: "Cost Objection Handling"
| Source | Variant | Nuance |
|--------|---------|--------|
| Glassdoor | "GCP 3x Teradata cost" | CTO, has spreadsheet |
| OfferEasy | "TCO shows savings but queries cost 3x" | FinOps lead, technical |
| interviews.chat | STAR-structured | Framework + evidence + pilot |
| JOYK | "Sales says consultants expensive" | Manager perspective, systemic fix |
| Dataford | Categorized: "Stakeholder Management" | Role-aligned, practical |

**Master Answer:** A.C.E. framework + TCO decomposition + Pilot close + Singapore reference (Bank X)
