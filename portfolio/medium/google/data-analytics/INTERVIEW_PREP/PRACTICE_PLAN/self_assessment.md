## 🎯 Competency Gate Checks

### Gate 1: End of Week 1 (Day 7)
**Must Pass to Proceed to Mocks:**
- [ ] Round 1: All 8 competencies ≥4
- [ ] Round 2: Technical cheat sheets complete, 15+ rapid-fire correct
- [ ] Round 3: 5 STAR stories recorded + peer reviewed
- [ ] Round 4: Presentation draft complete, whiteboard <5 min
- [ ] Round 5: 4 Google attribute STARs recorded, Singapore context cold

**If ANY unmet:** Add 2 days to Week 1, delay mocks. Do not proceed unprepared.

---

### Gate 2: After Mock Set 1 (Day 9)
**Must Improve to Proceed:**
- [ ] Mock 1 Overall: ≥3.0 average
- [ ] No Values Veto risk
- [ ] Top 3 gaps identified with specific drills
- [ ] Day 10 gap closure plan created

**If Mock 1 <3.0 average:** Root cause analysis. May need to repeat Week 1 focus areas.

---

### Gate 3: After Mock Sets 2-4 (Day 12)
**Must Achieve:**
- [ ] Technical average ≥3.5 (Mock 2)
- [ ] Leadership average ≥3.5 (Mock 3)
- [ ] Presentation average ≥3.5 (Mock 4)
- [ ] Whiteboard consistently <4:30

**If ANY dimension <3.5:** Targeted Day 13 practice before final mock.

---

### Gate 4: After Mock Sets 5-6 (Day 13)
**Must Achieve:**
- [ ] Cognitive average ≥3.5 (Mock 5)
- [ ] No Values Veto in any behavioral
- [ ] Curveball composure maintained (Mock 6)
- [ ] Singapore context cold under pressure

**If Values Veto risk:** Immediate rewrite of problematic STARs. Peer validation required.

---

### Gate 5: Final Mock (Day 14) - GO/NO-GO
**Must Achieve for Interview GO:**
| Round | Minimum Score | Your Score | GO? |
|-------|---------------|------------|-----|
| 1: Recruiter | Pass | | Y/N |

| 4: Presentation | ≥3.5 | | Y/N |
| 5: Cognitive | ≥3.5 | | Y/N |
| **Values Veto** | **NONE** | | **PASS/FAIL** |

**ALL GO = Interview Ready. ANY NO = Identify gap, targeted practice, reschedule if needed.**

- [ ] Architecture diagram drawn from memory <4 min (5x practice)
- [ ] Migration path doc printed (A3, color)
- [ ] Best practice asset demo ready (GitHub/Terraform/Notebook)
- [ ] Appendix slides accessible

### Logistics
- [ ] Interview time confirmed (timezone checked)
- [ ] Video link tested (Zoom/Meet/Teams)
- [ ] Camera, mic, lighting tested
- [ ] Backup internet (hotspot ready)
- [ ] Quiet, professional background
- [ ] Water, notebook, pen on desk
- [ ] Clothes ready (worn in Mock 10)

### Mental
- [ ] 3 questions for them prepared
- [ ] Values stories feel authentic (not memorized)
- [ ] Technical cheat sheets reviewed (not memorized)
- [ ] Sleep plan: 8 hours, no screens 1hr before
- [ ] Morning routine: light exercise, protein breakfast, review notes

### Emergency Kit
- [ ] Recruiter phone/email for technical issues
- [ ] Backup presentation on phone
- [ ] "I don't know but..." phrases on sticky note
- [ ] Breathing exercise for anxiety (4-7-8 technique)
