## 🎯 Round-by-Round Success Criteria

### Round 1: Recruiter Screen (30 min)
- [ ] 3-min narrative: quantified, migration-focused, Singapore-aware
- [ ] BigQuery architecture in 2 minutes (Colossus/Dremel/Borg)
- [ ] Cost objection: TCO decomposition + Pilot close
- [ ] Partner experience: governance model, not just "worked with SIs"
- [ ] Why Google Cloud Consulting Singapore: specific, not generic

### Round 2: Technical Deep-Dive (60 min)
- [ ] Live SQL: Customer 360 with late data, partitioning, clustering
- [ ] Live Beam: Pub/Sub→BQ with validation, DLQ, side input, exactly-once
- [ ] System Design: Real-time fraud (100K eps, <100ms, Vertex AI, audit)
- [ ] Tradeoffs: BQ vs Snowflake, Dataflow vs Kafka, Dataproc vs EMR
- [ ] Production reality: monitoring, runbooks, shuffle skew solutions

### Round 3: Consulting Simulation (45 min)
- [ ] Executive presentation: 10 min, 3 slides, skeptical CFO
- [ ] Scope creep negotiation: MoSCoW, data-driven, preserves relationship
- [ ] Technical disagreement: Seek to understand → tradeoff table → pilot both

### Round 4: Presentation (30 min + 15 Q&A)
- [ ] 20-slide deck: business outcomes first, technical depth on demand
- [ ] Whiteboard architecture: <4:30, labeled, tradeoffs noted, security visible
- [ ] Q&A: Top 10 questions answered with A.C.E. framework + Pilot close

### Round 5: Cognitive/Behavioral (60 min)
- [ ] **Googleyness**: 5 STARs (Failure, Influence, Objection, Priority, User Focus)
- [ ] **Leadership**: Team build, P&L, partner scaling, hiring, retention
- [ ] **Singapore**: MAS-TRM control mapping, PDPA architecture, partner names
- [ ] **Technical**: 20 rapid-fire in 30 min, 1 deep-dive
- [ ] **Objections**: 2 roleplays (Cost, Security/Lock-in/Timeline) with A.C.E.
- [ ] **NO VALUES VETO**: Humility, User Focus, Ambiguity, Influence
