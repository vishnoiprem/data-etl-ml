# Ugly Number II - 20 Ways

**Reference:** https://www.educative.io/courses/grokking-coding-interview-in-python/ugly-number-ii

## The Problem
```
Return the nth ugly number. An ugly number has prime factors limited to 2, 3, 5.
1 is ugly.

Examples:
    n=1 -> 1
    n=10 -> 12
    Sequence: 1, 2, 3, 4, 5, 6, 8, 9, 10, 12, 15, ...

Constraints:
- 1 <= n <= 1690
```

## How I Think (The Mental Process)

### Step 1: Understand
```
Generate ugly numbers in sorted order. Return the nth.
Each ugly number = 2^a * 3^b * 5^c.
```

### Step 2: The Trick
> "KEY INSIGHT: Three pointers (i2, i3, i5).
>
> - i2 = index of next ugly number to multiply by 2.
> - i3 = index of next ugly number to multiply by 3.
> - i5 = index of next ugly number to multiply by 5.
>
> Next ugly = min(ugly[i2]*2, ugly[i3]*3, ugly[i5]*5).
> Advance the pointer(s) that produced the minimum."

### Step 3: Why this works
> "Each ugly number has factors 2, 3, 5. Multiplying any ugly by 2, 3, or 5
> gives another ugly. We track which ugly to multiply next to produce the
> smallest NEW ugly in sorted order."

### Step 4: Algorithm
> "1. ugly = [1].
> 2. i2 = i3 = i5 = 0.
> 3. Loop until len(ugly) >= n:
>    - next = min(ugly[i2]*2, ugly[i3]*3, ugly[i5]*5).
>    - Append next.
>    - If next == ugly[i2]*2: i2 += 1.
>    - If next == ugly[i3]*3: i3 += 1.
>    - If next == ugly[i5]*5: i5 += 1.
> 4. Return ugly[n-1]."

### Step 5: Edge cases
> "- n=1: return 1.
> - Multiple pointers may advance (e.g., if next == ugly[i2]*2 == ugly[i3]*3)."

## What to Say Aloud in the Interview

**Opening:**
> "I need to find the nth ugly number in sorted order."

**Key Insight:**
> "Three pointers track which ugly number to multiply by 2, 3, 5 next. Take minimum, advance pointers."

**Algorithm:**
> "1. ugly = [1], pointers = 0, 0, 0.
> 2. For _ in range(n-1):
>    - next = min(ugly[i2]*2, ugly[i3]*3, ugly[i5]*5).
>    - Append next to ugly.
>    - Advance pointers that produced the minimum.
> 3. Return ugly[-1]."

**Why this works:**
> "Each ugly number is generated by multiplying an existing ugly by 2, 3, or 5. We track the next multiplier for each factor to maintain sorted order."

**Edge cases:**
- n=1: return 1.
- Duplicate values: advance ALL pointers that match.

**Complexity:**
- Time:  O(n).
- Space: O(n) for ugly list.

## The 20 Implementations (Simple to Complex)

### Way 1: Three pointers (BEST - Memorize!)
```python
def nthUglyNumber_1(n):
    ugly = [1] * n
    i2 = i3 = i5 = 0
    for i in range(1, n):
        next_ugly = min(ugly[i2] * 2, ugly[i3] * 3, ugly[i5] * 5)
        ugly[i] = next_ugly
        if next_ugly == ugly[i2] * 2:
            i2 += 1
        if next_ugly == ugly[i3] * 3:
            i3 += 1
        if next_ugly == ugly[i5] * 5:
            i5 += 1
    return ugly[-1]
```

## Best Answer to Memorize

```python
def nthUglyNumber(n):
    ugly = [1] * n
    i2 = i3 = i5 = 0
    for i in range(1, n):
        m = min(ugly[i2] * 2, ugly[i3] * 3, ugly[i5] * 5)
        ugly[i] = m
        if m == ugly[i2] * 2:
            i2 += 1
        if m == ugly[i3] * 3:
            i3 += 1
        if m == ugly[i5] * 5:
            i5 += 1
    return ugly[-1]
```

**~10 lines. O(n) time. O(n) space. Interview-ready!**

## Key Insights

### Why three pointers?
> "Each ugly is generated by multiplying an existing ugly by 2, 3, or 5. The pointer for each factor tracks which ugly to multiply next."

### Why advance ALL matching pointers?
> "If ugly[i2]*2 == ugly[i3]*3 (e.g., 6 = 2*3 = 3*2), both pointers should advance to avoid duplicate entries."

### Why heap works too?
> "Push u*2, u*3, u*5 for each popped u. Use set to avoid duplicates. Slower O(n log n) but conceptually simpler."

### What about supersets (2,3,5,7)?
> "Same algorithm generalizes to any prime set. Just add more pointers."

## Common Pitfalls

1. **Duplicate handling**: Multiple pointers may match. Advance ALL.
2. **IndexError**: Initialize pointers to 0, not 1.
3. **Off-by-one**: We want nth = ugly[n-1].
