# Two ways to install:
#   * Production (Databricks Job): the runtime cluster already
#     has most of these; pyproject.toml drives the wheel build.
#   * Local smoke: `pip install -r requirements.txt` then
#     `make smoke` runs a no-network iteration.
#
# Key design points:
#   * databricks-sdk 0.40+ provides WorkspaceClient, which is
#     the single entry point for Marketplace API, MLflow, UC,
#     Lakebase, and Foundation Model API.
#   * databricks-agents is the Mosaic AI Agent Framework.
#   * psycopg v3 (not v2) for Lakebase — same wire protocol
#     but better async, type hints, COPY support.
#   * No dbt, no Airflow, no Prefect — the Job IS the
#     orchestrator. That's the whole point.
