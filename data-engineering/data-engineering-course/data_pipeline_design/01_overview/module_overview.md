## What this module is

**This module is design-only.** There is no code, no service to run,
no test to pass. Read the lessons, then move to Module 02 to ground
the abstract concepts in concrete sources and sinks.

The point of Module 01 is to give you a *vocabulary* and a *framework*
that every later module builds on. If you only have time to read one
module in this track, read this one.

---

## What this module is not

It is **not** a tutorial on how to use Airflow, Spark, or Snowflake.
Those tools appear in later modules and the `code/` folders. This
module is the meta-lesson: how to *think* about pipeline design before
you commit to any tool.
