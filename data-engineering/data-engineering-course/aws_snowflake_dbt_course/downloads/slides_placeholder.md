# Slide deck placeholder

> **Author:** Prem Vishnoi <pvishnoi@avilx.com>

The published slide decks (PDF) for this course live on the
instructor's Google Drive / Notion workspace and are not bundled in
this repo (third-party copyright + large binary size).

When you enroll in the live course you receive a download link per
section. Each `lecture_scripts/L##_*.md` file references the
relevant slide via its filename in the `downloads:` frontmatter.

This placeholder keeps the folder present so the `SYLLABUS.md`
download paths resolve.
