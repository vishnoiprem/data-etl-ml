# Downloads

This folder ships **placeholder** copies of the PDF and zip resources
referenced from the lecture scripts. The real files are distributed
through the Udemy course page; the placeholders here exist so that
relative links in the lecture markdown resolve cleanly when you read
the repo locally.

| # | File | Purpose |
|---|---|---|
| 1 | `jwt_cheat_sheet.pdf` | All JWT claims, signing algorithms, library snippets in one page |
| 2 | `iam_policy_cheat_sheet.pdf` | Allow / Deny, statement structure, principalId / context |
| 3 | `api_gateway_event_shapes.pdf` | TOKEN vs REQUEST authorizer event reference |
| 4 | `lambda_authorizer_template_pack.zip` | SAM / CDK starter projects for sections 3–4 |

> The placeholders are intentionally empty files. If you'd like to
> redistribute the real files in this repo, drop them in here with the
> same names and the lecture links will resolve.
