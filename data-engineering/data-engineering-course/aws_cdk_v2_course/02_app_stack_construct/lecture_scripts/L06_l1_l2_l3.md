# L06 — L1, L2, L3 Constructs — When to Use Which

> **Author:** Prem Vishnoi &lt;pvishnoi@avilx.com&gt;

> **Duration:** 12:00

## Prereqs

L05 — The CDK construct tree

## Key terms

- **L1 (`Cfn*`)** — a 1-to-1 mapping to a CloudFormation resource.
  Verbose, no smart defaults.
- **L2 (`aws-*`)** — a curated AWS construct with sane defaults and
  helper methods. **Most of the time, this is what you want.**
- **L3 (patterns)** — a multi-resource pattern (`LambdaRestApi`,
  `ApplicationLoadBalancedFargateService`). Opinionated.

## Lecture

CDK gives you three escalating levels of abstraction. Most of the
time you want **L2**. Here's what each level looks like for S3:

```ts
// ── L1: 1-to-1 with CloudFormation ───────────────────────────────────
new s3.CfnBucket(this, 'Bucket', {
  bucketEncryption: {
    serverSideEncryptionConfiguration: [{
      serverSideEncryptionByDefault: { sseAlgorithm: 'AES256' },
    }],
  },
  publicAccessBlockConfiguration: {
    blockPublicAcls: true,
    blockPublicPolicy: true,
    ignorePublicAcls: true,
    restrictPublicBuckets: true,
  },
});
// → ~12 lines, you must know every CFN property name.

// ── L2: opinionated with sane defaults (encryption, public block) ──
new s3.Bucket(this, 'Bucket', {
  versioned: true,
  encryption: s3.BucketEncryption.S3_MANAGED,
  blockPublicAccess: s3.BlockPublicAccess.BLOCK_ALL,
});
// → 4 lines, gets encryption + public-block for free.
//    `bucketVersioned`, `bucketName`, `arn` etc. are exposed as properties.

// ── L3: pattern — multiple resources baked into one construct ───────
new s3.Bucket(this, 'Bucket'); // for the static-website version, see
// s3deploy.BucketDeployment + CloudFront in modules like `aws-cdk-lib/aws-route53`
```

**Decision tree:**

| If you want… | Use |
|---|---|
| A 1-to-1 CloudFormation resource with full control | **L1** (`CfnBucket`) |
| An opinionated resource that "just works" and exposes properties via methods | **L2** (`Bucket`) |
| A multi-resource pattern (e.g., REST API + Lambda + IAM) in one line | **L3** (`LambdaRestApi`) |

A common pattern is **L2 with an escape hatch to L1** — see L09.

## Hands-on

Look at `code/hello-cdk/lib/hello-cdk-stack.ts`. It uses `s3.Bucket`
(L2). Try changing it to `s3.CfnBucket` (L1) and re-running
`cdk synth` to compare the resulting CloudFormation templates.

```bash
cd 02_app_stack_construct/code/hello-cdk
npx cdk synth --quiet | jq '.Resources | length'  # count CFN resources
```
