# Answer Key

1. **B** — Gateway Load Balancer encapsulates customer flows in **GENEVE on UDP 6081**. GENEVE is the modern replacement for VXLAN, chosen by AWS for its flexible option/metadata headers. UDP 6081 is the IANA-registered port for GENEVE.

2. **B** — GWLB is **transparent inline**. The customer's source and destination IPs are preserved end-to-end, and the appliance is invisible at L3. ALB terminates the HTTP request, NLB terminates the TCP/UDP connection; GWLB does neither.

3. **B** — A GWLB is always deployed across exactly **two subnets in two different Availability Zones**. Same constraint as NLB. This gives zonal redundancy at the GWLB level. Health checks rotate traffic among healthy appliance targets within an AZ; if an AZ goes down, the other AZ keeps serving.

4. **B** — GWLB uses the **5-tuple** (source IP + destination IP + protocol + source port + destination port) as the hash key for flow stickiness. This guarantees that all packets of a single TCP/UDP flow land on the same appliance instance, so the appliance can track state for the flow.

5. **C** — The production pattern is **PrivateLink via a VPC endpoint service**: front the GWLB with a Network Load Balancer, register the NLB as an endpoint service, and have consumer VPCs (or on-prem via DX) connect through interface endpoints. This avoids VPC peering, scales to many consumers, and keeps the appliance VPC private.

6. **C** — A GWLB target group is `Protocol='GENEVE'`, `Port=6081`. Health checks are typically `HTTP` on `/health` because the appliance itself exposes an HTTP management endpoint.

7. **C** — Transparent L3 forwarding of a customer flow to a third-party firewall is exactly what **Gateway Load Balancer** does — it is *not* an ALB feature. ALB terminates HTTP/HTTPS at L7; it cannot preserve the original L3 source/destination through a third-party appliance. Host-based routing, path-based routing, and WebSockets are all native ALB features.

8. **A** — The first thing to try on `InsufficientInstanceCapacity` is to **switch to a different instance type** and retry. The error means AWS does not have enough of that specific type in that specific AZ right now; a different type (e.g. `t3.small` or `t4g.small`) usually has capacity. B is overkill; C is the wrong axis; D is unrelated.

9. **B** — NLB's default is **cross-zone load balancing OFF**. Each AZ's targets only receive traffic that is routed to that AZ (typically because the client's local resolver picked that AZ's IP, or because of how the DNS records round-robin). You can turn cross-zone on, but you pay an inter-AZ data-transfer charge for the cross-AZ traffic. (ALB's default is the opposite — cross-zone is **on** by default.)

10. **D** — **Spot Instances** give the largest discount (up to ~90% off On-Demand) in exchange for AWS being able to reclaim the instance with 2 minutes' notice. Reserved Instances and Savings Plans trade flexibility (1- or 3-year commitments) for a smaller discount (typically 30-60% off). On-Demand is the most flexible and most expensive.
