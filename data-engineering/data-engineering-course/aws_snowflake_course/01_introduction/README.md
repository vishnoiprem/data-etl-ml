## Key concepts you'll need later

- **Snowflake = cloud-native SaaS data platform**, runs on AWS,
  Azure, GCP.
- **Two main cost drivers** — compute (per-second warehouse
  billing) and storage (per-TB-per-month).
- **The repo layout** — `code/`, `assignments/`, `diagrams/`,
  `downloads/`, `quizzes/`, `scripts/`.
- **The four study strategies** — watch+code, free trial,
  end-to-end project, take quizzes seriously.
