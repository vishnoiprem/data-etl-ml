## What this lecture covers

- A 1-minute summary of Section 1: the AWS fundamentals you need before you can use Glue.

## Narration

> "Section 1 is the AWS fundamentals. We'll cover 4 services: IAM for authentication and authorization, KMS for encryption keys, SNS for pub/sub, and a quick survey of how Glue fits in. By the end of this section, you'll be able to set up an IAM user, attach a policy, create a KMS key, and publish to an SNS topic. The hands-on part is the `GlueJobRole` IAM role — every Glue Job needs one, and it's the most common source of bugs."

## Section 1 deliverables

1. **IAM lab**: create an IAM user + group (Lecture L6).
2. **IAM role lab**: create a `GlueJobRole` for Glue to assume (Lecture L7).
3. **IAM policies**: read + write a policy document (Lecture L8).
4. **KMS lab**: create a KMS key, encrypt + decrypt (Lecture L9).
5. **SNS lab**: create a topic, publish a message (Lecture L10).
6. **GlueJobRole**: the culminating artifact (Lecture L12).
