# L06 — IAM Lab: Setting Up Users and User Group

> **Author:** Prem Vishnoi &lt;prem.vishnoi@example.com&gt;
> **Section:** 1 — Introduction
> **Duration target:** 2:59

## What this lecture covers

- The first IAM hands-on: create an IAM user, create a user group, attach a policy to the group, add the user to the group.

## Narration

> "Let's set up an IAM user. We'll do this from the AWS console. Open IAM, click 'Users', click 'Add user'. Give the user a name — let's call it `glue-course-user`. Enable 'Programmatic access' (this gives the user an access key + secret for the AWS CLI) and 'AWS Management Console access' (so they can log in to the console). For the console password, choose 'Autogenerated' or 'Custom' depending on your preference. Click 'Next: Permissions'. Now we need to add the user to a group. Click 'Create group'. Name the group `glue-course-developers`. Attach the `AdministratorAccess` managed policy — for this lab, full admin is fine; in production, you'd use a least-privilege policy. Click 'Create group'. The user is now a member. Click 'Next: Tags' (skip), 'Next: Review' (verify), 'Create user'. Save the access key + secret — you will not see them again."

## Lab steps

1. IAM → Users → Add user.
2. Name: `glue-course-user`. Enable Programmatic access + Console access.
3. Create group: `glue-course-developers`. Attach `AdministratorAccess`.
4. Add user to group.
5. Create user. Save the access key + secret.

## Acceptance criteria

- The user `glue-course-user` exists in IAM.
- The user is a member of the group `glue-course-developers`.
- The group has `AdministratorAccess` attached.
- You can log in to the console as the user.

## On-screen

- The 5-step wizard: Set user details → Set permissions → Add tags → Review → Create.
