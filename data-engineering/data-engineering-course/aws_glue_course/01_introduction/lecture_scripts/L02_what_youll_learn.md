## Narration

> "Here are the 8 things you'll be able to do by the end of the course. One: understand the AWS Glue Data Catalog and create Glue Databases, Glue Tables, and Crawlers. Two: use **AWS Glue Studio** — the visual drag-and-drop ETL builder — and create ETL pipelines with **scheduled triggers, conditional triggers, and Glue Workflows**. Three: understand and create KMS keys, IAM roles, SNS topics, S3 buckets, and the other AWS resources Glue depends on. Four: understand AWS Glue Data Quality and create a Data Quality-enabled Glue ETL pipeline. Five: understand AWS Glue DataBrew — create recipes, projects, and jobs to curate datasets. Six: understand AWS Glue Streaming — generate streams with Python shell jobs and load them with Spark streaming jobs. Seven: identify the different ways a Glue Job can fail, debug the failure, and fix it. Eight: create Glue pipeline resources using both the AWS console and CloudFormation. Each of these maps to a section. Outcome 1 is Section 5. Outcome 2 is also Section 5 plus Section 7. Outcome 3 is Sections 2-4. Outcome 4 is Section 10. Outcome 5 is Section 11. Outcome 6 is Section 9. Outcome 7 is Section 8. Outcome 8 is Sections 6-7."

## The 8 outcomes (verbatim from the course description)

1. Understanding of AWS Glue Data Catalog and creating AWS Glue Database, Glue Tables and Crawlers.
2. Using AWS Glue Studio, creating the ETL pipeline along with scheduled triggers, conditional triggers and glue workflow.
3. KMS, IAM Role, SNS, S3 and other associated AWS resources associated with Glue. Understanding and creation of all the resources.
4. Understanding of AWS Glue Data Quality and creating the associated Glue ETL pipeline.
5. Understanding AWS Glue Data Brew, creating the recipe, project and job to curate the dataset.
6. Understanding the AWS Glue streaming, creating the stream using the Python shell job and load the stream using the Spark streaming.
7. Different ways AWS Glue job can fail and debugging the failure and fix.
8. Creating the AWS resources for AWS Glue Pipeline using the AWS console and cloudformation.
