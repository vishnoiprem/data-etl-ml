# 06 — Bonus: AI-Assisted Coding Round at Meta

> **Author:** Prem Vishnoi <prem.vishnoi@example.com>

A growing number of companies (Meta most visibly) are now running coding rounds where you can use an AI assistant. The format looks like:

- You're given a problem, IDE, and a coding assistant (Copilot, internal tool).
- You can ask the assistant for help but you must own the final code.
- Interviewers watch how you **steer** the AI, not how fast you type.

## Tips

1. **Be the driver.** Use the AI to draft boilerplate (e.g. BFS skeleton), not to design the algorithm.
2. **Verify everything.** AI hallucinations are common on edge cases.
3. **Explain your prompts out loud.** "I want a deque-based BFS that returns the shortest path length."
4. **Don't paste the whole problem in.** Companies look for that. Restate the constraints.
5. **Treat the AI like a junior dev.** Code review its output, then own the result.

The rest of this course deliberately uses no AI — the value is in *your* problem-solving muscles. When the AI is allowed, you'll have them.
