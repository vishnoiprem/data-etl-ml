The published course bundles PDF slide decks for several key
lectures. In this open-source companion repo the slides are linked
from the Udemy course page; the files below are placeholders so the
directory structure mirrors the course's published layout.

| File | Description |
|---|---|
| `slides.pdf` | Master deck covering all 36 lectures (~110 slides). |
| `study_guide_event_patterns.pdf` | Companion to L11–L14. |
| `study_guide_pipes_archives.pdf` | Companion to L25–L28. |
