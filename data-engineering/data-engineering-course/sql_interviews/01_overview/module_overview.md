# Module 01 — Overview

> **3 lessons · 0 videos · ~30 minutes**
>
> **Author:** Prem Vishnoi &lt;prem.vishnoi@example.com&gt;

The shortest module. Before you write a single query, set the
stage: where SQL came from, how to recognize and answer the kind
of question an interviewer asks, and the relational foundations
that make the language tick.

These three lessons are short on purpose. The point is to give
you a frame, not to teach you syntax. Syntax comes in M02.

---

## What this module covers

| # | Lesson | What you'll learn |
|---|---|---|
| [01](design/01_intro_to_sql.md) | Introduction to SQL and Its History | Why SQL exists, who created it, why it survived 50 years. |
| [02](design/02_answering_sql_questions.md) | How to Answer SQL Interview Questions | The 5-step framework: clarify → sketch → write → verify → explain. |
| [03](design/03_relational_concepts.md) | Relationships and Relational Database Concepts | Relations, tuples, keys, referential integrity — the vocabulary. |

---

## How to read this module

Read the lessons in order, but don't try to memorize them. The
goal is to internalize the framework in Lesson 02 — you'll use
it on every problem in M07 through M09.
