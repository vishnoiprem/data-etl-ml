# Module 06 — Window Functions

> **4 lessons · 0 videos · ~1 hour**
>
> **Author:** Prem Vishnoi &lt;prem.vishnoi@example.com&gt;

The deepest SQL feature for interviews. By the end of M06
you should be comfortable with `ROW_NUMBER`, `RANK`,
`DENSE_RANK`, `LAG`, `LEAD`, `FIRST_VALUE`, `LAST_VALUE`,
`NTILE`, `CUME_DIST`, `PERCENT_RANK`, and frame clauses
(`ROWS BETWEEN ...`). These four lessons are the difference
between "I can write SQL" and "I can solve hard interview
problems".

M06 is short on prose and dense on examples. Read each
lesson, type the example queries, and try the exercises
without looking.
