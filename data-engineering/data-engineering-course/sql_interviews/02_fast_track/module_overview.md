# Module 02 — Fast Track

> **9 lessons · 0 videos · ~1.5 hours**
>
> **Author:** Prem Vishnoi &lt;prem.vishnoi@example.com&gt;

The syntax you must know cold. After M02 you should be able to
read any of the canonical interview queries and recognize every
clause. You don't need to *memorize* — you need to be able to
*write it from memory* under interview pressure.

The lessons are short and dense. Read each one once, then
type out the example query without looking. If you can write
it twice in a row without error, you know it.

## How to read this module

Each lesson ends with a "try it" exercise. The exercise is
deliberately small. The point is to get a query from your
brain to your editor without looking. Do the exercise for
every lesson before moving on.
