## 1. Hard Lambda limits (single-function)

| Limit | Value | Notes |
|---|---|---|
| Memory | 128 MB – 10,240 MB | Set in 1-MB steps. |
| Ephemeral disk (`/tmp`) | 512 MB – 10,240 MB | Scales 1:1 with memory above 1,792 MB. |
| Timeout | 1 s – 900 s (15 min) | Hard ceiling 900. |
| Payload (invoke / async) | 6 MB (sync), 256 KB (async) | Use S3 for larger. |
| Function + layer zip | 250 MB unzipped, 50 MB zipped | Container images up to 10 GB. |
| Container image | 10 GB | ECR only. |
| Env vars (total) | 4 KB | Across all keys. |
| Function name | 64 chars | Same as `arn:FunctionName` segment. |
| Concurrent executions (default) | 1,000 per region | Soft cap; raise via support ticket. |
| Burst concurrency | 500 – 3,000 (region-dependent) | Drained over minutes. |
| Function versions | unpublished + published (no hard cap on published) | Each `$LATEST` + N versions. |
| Aliases | 10 per function | |
| Layers | 5 per function | Order matters. |
| VPC ENIs | 1 per subnet, max 250 ENIs per function | Account-wide default. |
| Log retention | never expire by default | Set in log group. |

## 4. AWS CLI quick reference (Lambda)

### Create / update

```bash
# zip and create
zip -j function.zip handler.py
aws lambda create-function \
  --function-name my-fn \
  --runtime python3.12 \
  --role arn:aws:iam::111122223333:role/lambda-role \
  --handler handler.handler \
  --zip-file fileb://function.zip \
  --memory-size 512 --timeout 30

# update code only
aws lambda update-function-code \
  --function-name my-fn \
  --zip-file fileb://function.zip

# update config (memory, timeout, env, role)
aws lambda update-function-configuration \
  --function-name my-fn \
  --memory-size 1024 --timeout 60 \
  --environment "Variables={LOG_LEVEL=INFO,FEATURE_X=on}"
```

### Invoke

```bash
# sync
aws lambda invoke --function-name my-fn --payload '{"k":"v"}' out.json
# async
aws lambda invoke --function-name my-fn --invocation-type Event --payload '{}' out.json
# tail logs after
aws logs tail /aws/lambda/my-fn --follow
```

### Versions + aliases

```bash
aws lambda publish-version --function-name my-fn
# -> Version: 1

aws lambda create-alias \
  --function-name my-fn --name prod --function-version 1

aws lambda update-alias \
  --function-name my-fn --name prod --function-version 2

aws lambda get-alias --function-name my-fn --name prod
```

### Concurrency

```bash
aws lambda put-reserved-concurrency-execution-config \
  --function-name my-fn --reserved-concurrent-executions 50

aws lambda put-provisioned-concurrency-config \
  --function-name my-fn --qualifier prod \
  --provisioned-concurrent-executions 5
```

### Event source mappings

```bash
aws lambda create-event-source-mapping \
  --function-name my-fn \
  --event-source-arn arn:aws:sqs:us-east-1:111:q \
  --batch-size 10 --function-response-types ReportBatchItemFailures
```

### Layers

```bash
aws lambda publish-layer-version \
  --layer-name my-layer \
  --zip-file fileb://layer.zip \
  --compatible-runtimes python3.12

aws lambda update-function-configuration \
  --function-name my-fn \
  --layers arn:aws:lambda:us-east-1:111:layer:my-layer:1
```

## 5. Pricing (us-east-1, 2026)

- **Requests:** $0.20 per 1 M requests.
- **Duration:** $0.0000166667 per GB-second (x86), $0.0000133334 per GB-second (arm64 / Graviton2).
- **Provisioned concurrency:** $0.0000041667 per GB-second + duration charges.
- **Ephemeral storage above 512 MB:** $0.0000000309 per GB-second.

Free tier (per month, never expires for accounts created after 2025):

- 1 M requests.
- 400,000 GB-seconds of compute.

## 7. Context object (`context`) fields

| Field | Type | Notes |
|---|---|---|
| `function_name` | str | Same as `AWS_LAMBDA_FUNCTION_NAME`. |
| `function_version` | str | `$LATEST` or numeric. |
| `invoked_function_arn` | str | The ARN that triggered this invocation. |
| `aws_request_id` | str | Unique per invoke; return in error responses for tracing. |
| `log_group_name` | str | CloudWatch Logs group. |
| `log_stream_name` | str | CloudWatch Logs stream. |
| `identity` | dict | Set for API GW / Cognito; `cognito_identity_id`, `cognito_authentication_type`, `caller`, `source_ip`, `user`, `user_agent`. |
| `client_context` | dict | Set for mobile SDK invocations. |
| `get_remaining_time_in_millis()` | method | Returns ms until timeout. |
| `callback` | callable | For the (legacy) Node.js async handler pattern. |

## 8. One-liner pro tips

- Set `AWS_LAMBDA_LOG_LEVEL` to `DEBUG` in env to get `[DEBUG]` lines from the runtime.
- Use `aws lambda get-function-configuration` (note the singular) for current config; `get-function` returns the same + code info.
- For a 6 MB payload limit, use S3 + pre-signed URL or API Gateway's binary passthrough.
- Use `lambda:ProvisionedConcurrencyUtilization` CloudWatch metric to right-size provisioned concurrency.
- For VPC Lambdas, allocate **at least 2 subnets in different AZs** for HA; the ENI scheduler needs them.
