# Section 3 — Python Basics Refresher (L09–L10)

> **Author:** Prem Vishnoi &lt;prem.vishnoi@example.com&gt;
> **Lectures:** L09 (Part 1, 8:00) + L10 (Part 2, 15:11) — 23 min total

This section is a focused, two-lecture Python refresher for students who are
new to Python or want a fast brush-up before we start writing Lambda
handlers in section 4. **L09** covers the absolute basics — variables,
primitive types, f-strings, conditionals, loops, and functions (including
`*args` and `**kwargs`). **L10** levels up to comprehensions, error
handling, modules, virtual environments, and a first taste of the
`boto3` client interface that we will rely on for the rest of the course.

If you already write Python daily, you can skim L09 and focus on L10
(especially the virtual environment + boto3 client material). If you have
never written Python before, watch L09 once at 1x and once again while
typing every example.
