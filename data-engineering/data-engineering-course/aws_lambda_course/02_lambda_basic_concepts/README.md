# Section 2 — AWS Lambda Basic Concepts (Part 1)

> **Author:** Prem Vishnoi &lt;pvishnoi@avilx.com&gt;
> **Lectures:** L03–L08
> **Duration:** ~26 min

This section lays the conceptual foundation for everything that follows. We start
with a brief 22-second overview, then walk through the **evolution from physical
servers to serverless** so the Lambda mental model makes sense in context. We
define what AWS Lambda actually is, look at the four pricing dimensions, and
talk about when Lambda is a good fit and when it is not.

We then spend a full lecture in the AWS console — clicking through **Create
function → runtime → handler → trigger → test** — so you have a working
end-to-end picture before we touch code in Section 4. We close with the **Lambda
execution role** (IAM basics every Lambda author must know) and a short
**conceptual review** with self-check questions.

By the end of this section you should be able to describe Lambda to a
colleague, decide whether it fits a given problem, and run a function in the
console without referring back to the docs.
