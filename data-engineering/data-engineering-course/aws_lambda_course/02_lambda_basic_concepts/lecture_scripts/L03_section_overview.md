## Key terms

- **AWS Lambda** — AWS's Function-as-a-Service (FaaS) offering.
- **Serverless** — execution model where AWS manages the servers; you supply only code.
- **Execution role** — the IAM role Lambda assumes to call other AWS services on your behalf.

## Lecture

Welcome to Section 2 — **AWS Lambda Basic Concepts (Part 1)**.

In the next six lectures — about 26 minutes total — we'll build a working
mental model of AWS Lambda before we write a single line of code:

- **L04** — how the industry got from physical servers to serverless, and
  where Lambda fits in that arc.
- **L05** — what AWS Lambda actually is, the four pricing dimensions, and
  when to choose it (and when not to).
- **L06** — a detailed click-through in the AWS console: create a function,
  pick a runtime, write a handler, add a trigger, and test it.
- **L07** — the Lambda execution role, the
  `AWSLambdaBasicExecutionRole` managed policy, and the principle of
  least privilege.
- **L08** — a short conceptual review with self-check questions so you can
  confirm the mental model has stuck before we move on to Python in
  Section 3 and boto3 in Section 4.

Let's get started with L04.
